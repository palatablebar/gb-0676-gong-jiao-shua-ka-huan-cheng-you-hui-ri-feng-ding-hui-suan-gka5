# 数据定义

刷卡事件以event_id去重，card保留前导零。route支持1路/01等别名。event_time必须带偏移；业务日为Asia/Shanghai。result仅success可作为行程，失败刷卡隔离。reported为实扣人民币元。票价F1至2026-11-01前为2元，F2为2.50元。

## 刷卡文件列

必填列及顺序：`event_id,card,route,event_time,result,reported,note`。可选尾列 `vehicle`、`task_id` 分别表示车载机号与调度任务号；存在时参与线路归属，缺失时整列视为空。多余或重复的可选列按表头不匹配拒绝。

## 调度依据

调度依据是独立的CSV，列固定为 `task_id,vehicle,route,start,end`。时间为带偏移时刻，区间为[start,end)，`end` 可空表示持续有效；`end` 不晚于 `start` 隔离。线路按车辆任务填写，route支持与刷卡相同的别名。

**线路裁决**：临时改道或跨线借车期间，以覆盖本次刷卡的调度任务线路作为票务线路（`fare_route`）；车载机打印编码（`printed_route`）始终保留为证据，仅在调度无法裁决时回退使用：未提供调度依据、刷卡无任务号、任务未登记、任务时段未覆盖、车辆与任务不符。回退原因逐行写入 `line_source` 与 `line_note`。

任务切换失败（同任务或同车辆时段重叠）时，冲突调度行隔离并保留原因，先前可读版本继续生效，不得因失败切换删除旧版。同一任务重复提交完全相同的归属视为重试，不新增任务版本。同任务同线路仅修订时段时，新版本覆盖旧版本；旧行转入 `superseded_rows` 留档，线路归属不变。

## 规则

跨线路换乘以采用的票务线路判定，必须在上一次实际付费行程后60分钟内，恰好60分钟排除。同线路无优惠；零付费行程不能延长换乘锚点。先扣1元换乘优惠，再对卡号业务日施加6元封顶。每条基本票价=实算扣费+换乘优惠+封顶优惠。每张卡每个业务日只保留一套换乘与封顶结果；不另按打印编码生成第二套。

页面逐程展示实际任务、打印编码、采用的票务线路、线路依据与说明，以及 `printed_expected`（若按打印编码归并的应扣）与 `line_difference`（线路裁决差异）。`printed_route` 为归一化后的打印编码，未登记时为 null；原始字面值另存 `printed_raw`，不因归一化或回退丢失。

业务ID和超大整数按文本保形；Decimal参与数量金额计算，对外序列化为字符串。哨兵集合定义在app/values.py，缺失值不能当零。所有时间带UTC偏移，先转UTC比较，业务日按指定地区划分。区间统一[start,end)。重复业务键保留第一条、完全相同行计重复；值冲突行隔离且保留原值。空文件、全空白、仅表头分开拒绝。

运行清单包括输入sha256、调度依据sha256、规则版本、参数、生成时刻与耗时。源行编号以CSV解析器的物理结束行号表示，引号内换行不增加记录数；调度来源行以 `dispatch:<行号>` 标识。输入超过4MB返回413，非法表头和类型返回422，失效版本复核返回409。

## 归档

台账同时导出采纳行、隔离行、调度采纳行、调度隔离行以及重试/空白调度行，原始刷卡行与调度依据均保留 `_raw` 与来源行。M6核对刷卡来源行守恒且 `dispatch_balanced` 为真；M7在调度 `gaps` 非零、刷卡来源行未对平、同卡同日出现多套结果或换乘锚点不属于同套结果时拒绝封存。
